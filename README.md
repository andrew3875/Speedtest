# Internet Speed Tester

Скрипт для измерения скорости загрузки данных с указанного URL.

Скрипт последовательно выполняет 10 HTTP-запросов к указанному адресу, измеряет время каждого запроса и объём полученных данных, после чего рассчитывает среднее время запроса и среднюю скорость загрузки.

## Requirements

* Python 3.8+
* `requests`

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/USERNAME/internet-speed-tester.git
cd internet-speed-tester
```

Установите зависимость:

```bash
pip install -r requirements.txt
```

## Использование скрипта

Запустите скрипт, передав URL файла для скачивания:

```bash
python speedtest.py "https://example.com/large-file.jpg"
```

Для корректного измерения рекомендуется использовать достаточно большой файл.

## Пример

```text
Request 1: 0.842 s, 10.25 MB, 12.17 MB/s
Request 2: 0.791 s, 10.25 MB, 12.96 MB/s
Request 3: 0.815 s, 10.25 MB, 12.58 MB/s
...
Request 10: 0.803 s, 10.25 MB, 12.77 MB/s

Results:
Successful requests: 10/10
Average request time: 0.812 s
Downloaded data: 102.50 MB
Average speed: 12.62 MB/s
```

## Алгоритм работы

Для каждого запроса скрипт:

1. Запоминает время начала запроса.
2. Выполняет HTTP GET-запрос.
3. Дожидается полного получения ответа.
4. Определяет объём полученных данных.
5. Вычисляет скорость загрузки.
6. Выводит результат в консоль.

После 10 запросов рассчитываются общие результаты.

Средняя скорость рассчитывается как:

```text
total downloaded data / total download time
```

Скорость указана в **MB/s** (мегабайт в секунду).

## Обработка исключений

Если отдельный запрос завершается ошибкой или превышает установленный timeout, скрипт выводит сообщение об ошибке и продолжает выполнение остальных запросов.

Если не удалось выполнить ни одного запроса, скрипт сообщает об отсутствии успешных запросов.
